# shared files

hi!

this folder contains files and documentation that are useful across the avera project.

instead of keeping common things inside individual hardware versions, i'm putting them here so they can be reused.

currently, this includes the communication protocol documentation used by the development setup.

## folders

- `protocol/` contains documentation about how different parts of avera communicate with each other.

## why is this separate?

the hardware might change between versions, but some things can stay the same.

for example, the way sensor readings are named or how data is sent to avera-console can be kept consistent even when the actual hardware changes.
